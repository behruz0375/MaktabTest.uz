## 1-QADAM: Kodni GitHub'ga yuklash

Render kodni GitHub'дан oladi. GitHub — bu kod saqlaydigan bepul sayt.

### Eng oson yo'l — GitHub Desktop (tavsiya)
1. [desktop.github.com](https://desktop.github.com) — GitHub Desktop dasturini yuklab o'rnating.
2. Ochib, **Sign in** — GitHub akkaunt oching (bepul, faqat email kerak).
3. **File → Add local repository** → `C:\Users\User\Desktop\MaktabTest.uz` papkasini tanlang.
4. **Publish repository** tugmasini bosing. "Keep this code private" belgisini **olib tashlang** (Public bo'lsin). **Publish**.
5. Tayyor! Kod GitHub'да.

### Yoki — sayt orqali (dastursiz)
1. [github.com](https://github.com) da ro'yxatdan o'ting.
2. **New repository** → nom bering (masalan `maktabtest`) → **Public** → **Create**.
3. **uploading an existing file** havolasini bosing → `MaktabTest.uz` papkasidagi **hamma fayllarni** sudrab tashlang (`data` papkasidan tashqari) → **Commit**.

## 2-QADAM: Render'ga joylash

1. [render.com](https://render.com) ga kiring → **Get Started** → GitHub bilan ro'yxatdan o'ting (bepul).
2. Yuqorida **New +** → **Blueprint**.
3. GitHub'даги `maktabtest` repongizni tanlang → **Connect**.
4. Render `render.yaml` faylni o'zi o'qiydi va hammasini sozlaydi. **Apply** / **Create** bosing.
5. 3-5 daqiqa kuting (birinchi marta biroz sekin).
6. Tayyor bo'lganда yuqorida **havola** chiqadi, masalan:
   `https://maktabtest.onrender.com`

Bu havola **doimiy** — o'shani hammaga yuboring! 🎉

### Ma'lumot abadiy saqlanishi uchun (tavsiya) — ~$7/oy

2. Rejani **Starter** ($7/oy) ga o'zgartiring.
3. `render.yaml` fayl ichидаги izohда ko'rsatilgан **disk** sozlamasini qo'shing (yoki menga ayting — men tayyorlab beraman).

### Butunlay bepul + ma'lumot saqlanadigan muqobil
